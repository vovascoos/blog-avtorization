# blog-avtorization
Простой блог на Flask с регистрацией и авторизацией. Пользователи могут создавать посты, которые сохраняются в базу данных SQLite. 

Что умеет:
Регистрация новых пользователей
Вход/выход из аккаунта
Создание постов (только для авторизованных)
Просмотр всех постов на главной странице
Хэширование паролей через werkzeug

Стек:
Python 3.7+
Flask
Flask-SQLAlchemy
SQLite
HTML + CSS
